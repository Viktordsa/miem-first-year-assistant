# Помощник первокурсника ИВТ МИЭМ

Прототип отвечает на вопросы по открытым программам **первого курса ИВТ НИУ ВШЭ за 2026/2027 учебный год**. Показывает краткую выдержку, название раздела и ссылку на официальный источник. В базе 25 программ, включая обычные, углублённые и индустриальные варианты. Снимок получен 22.10.2026 с двух страниц отфильтрованного каталога.

## Запуск за минуту

Нужен Python 3.10 или новее. Внешние библиотеки, API-ключи и интернет для работы не нужны.

```sh
python server.py
```

Откройте http://127.0.0.1:8765 в браузере. Выберите дисциплину и задайте вопрос. Остановка — Ctrl+C. Если команда `python` отсутствует в Windows, попробуйте `py`.

Примеры: «Какая формула промежуточной аттестации?», «Какая основная литература рекомендована?», «Какие темы входят в содержание дисциплины?». Дисциплину можно выбрать в списке: это надёжнее автоматического распознавания названия.

Командная строка:

```sh
python assistant.py "Какие темы изучает Дискретная математика?"
```

## Как работает

1. `tools/collect.py` обходит обе страницы официального каталога с фильтрами первого курса и 2026 года. Сохраняет исходные HTML, URL и SHA-256 для проверки происхождения.
2. Проверяет наличие учебного года и первого курса на странице программы. Извлекает паспорт, содержание, цели, результаты, контроль, аттестацию и литературу по заголовкам разделов. Из аттестации исключаются блоки других учебных лет: некоторые программы охватывают несколько лет.
3. `assistant.py` определяет дисциплину и тип вопроса, ищет в соответствующих разделах. Использует нормализацию слов и лексическое ранжирование с весами редких слов (упрощённый TF-IDF). Длинные разделы разбиваются на окна по 1000 символов с перекрытием 120.
4. Возвращает до двух фрагментов, сокращённых до 850 символов каждый, и источники. Это **экстрактивное резюмирование**, без генеративной LLM. Прямые выдержки сохраняют проверяемость и позволяют запустить проект без платных сервисов.

Выбор подхода: небольшой фиксированный корпус; быстрый и воспроизводимый запуск; низкая стоимость; отсутствие зависимости от API. Компромисс — слабое понимание синонимов и отсутствие сложного синтеза. Подход не претендует на полноценный семантический RAG.

## Результаты тестирования

```sh
python tools/evaluate.py
python -m unittest discover -s tests -v
```

`output/test-results.md` — 30 реальных запросов с ответами и источниками. 20 базовых вопросов проверяют содержание, формулы, литературу и модули пяти дисциплин. 10 сложных вопросов раскрывают недостатки. Машиночитаемые результаты — `output/test-results.json`.

20/20 базовых проверок проверяют наличие заранее указанного факта и правильного URL. Это не 100% точность на произвольных вопросах: набор небольшой, часть вопросов использует выбранную дисциплину, проверка не оценивает полноту всего ответа. Сложные вопросы не включены в этот показатель.

## Обновление базы

```sh
python -m pip install -r requirements.txt
python tools/collect.py
```

Загрузчик использует кэш. Для повторной загрузки перенесите старую папку `data/raw` в резервную копию перед запуском. Проверьте `data/manifest.json`, список принятых дисциплин и заново запустите тесты. Если сайт недоступен, используйте включённый снимок; не подменяйте его программами другого года.

## Ограничения

- Ответ может быть неполным: выдача ограничена длиной и числом фрагментов. Полная программа доступна по ссылке.
- Нет калькулятора оценок, диалога с памятью, плана подготовки и сравнения нескольких программ.
- Русские окончания обрабатываются грубо; разговорные названия, опечатки и английские вопросы могут давать ошибки.
- Наличие релевантных слов не гарантирует, что фрагмент отвечает на вопрос. Порог отказа эвристический.
- Нет расписания, персональных оценок и материалов из закрытой LMS.
- Страница дисциплины может описывать несколько курсов; темы такой программы не всегда размечены по годам. Блоки аттестации других лет отфильтрованы, распределение тем по годам требует ручной сверки.
- Англоязычные заголовки экзамена по английскому распознаются не полностью.
- Источники — снимок на указанную дату; обновления сайта автоматически не подхватываются.

## Что улучшить за два дня

День 1: проверить корпус вручную, выделить формулы и условия оценивания в структурированные поля, добавить морфологию, словарь сокращений и семантические эмбеддинги; расширить независимый тестовый набор.

День 2: добавить генерацию краткого ответа по найденным фрагментам с проверкой цитат, сравнение двух дисциплин и безопасный калькулятор формул; отдельно измерить полноту ответа, правильность источников и качество отказов. Генеративную модель включать через переменные окружения, ключи не хранить в репозитории.

## Публикация в открытом репозитории

Создайте **public** репозиторий GitHub и загрузите содержимое этой папки, включая `data`, `output`, `tools` и `tests`. Для сдачи нужен адрес страницы репозитория. Убедитесь, что он открывается в приватном окне без входа. Локальная папка или архив публичную ссылку не заменяют.

Данные программ принадлежат НИУ ВШЭ и их авторам; включены как снимок открытых источников для воспроизводимости прототипа. URL и контрольные суммы — в `data/courses.json`.
